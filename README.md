# 闪烁探测器波形解卷积审计页

高计数率下相邻光子脉冲在闪烁探测器波形中堆叠成一条记录。本工具把「逐峰扣除」换成
**可重算的离线解卷积**：全部计算在浏览器本地完成（TypeScript + React，无任何业务后端、
不访问在线服务），复核员修改输入即可即时重算，结果可审计、可复现。

## 问题定义与求解规则

- 观测波形 `w[0..m−1]`：长度 **12–300** 的非负整数；
- 探测器响应核 `h[0..k−1]`：长度 **2–7** 的非负整数，且**首项与末项必须为正**；
- 每个采样点的脉冲数上限：**0–4** 的整数；
- 潜在脉冲序列 `x[0..n−1]`，**n = m − k + 1**，重建为零边界卷积
  `y[t] = Σ_j x[j]·h[t−j]`，凡越界项一律按零处理。

系统依次按三层规则确定规范解（全部为精确动态规划，非近似）：

1. **第一层**：最小化绝对残差总和 `Σ_t |w[t] − y[t]|`；
2. **第二层**：在第一层同优解中最小化脉冲总数 `Σ_j x[j]`；
3. **第三层**：仍并列时取脉冲向量**字典序最小**者作为规范解。

同时，对每个脉冲位置给出**全部双层同优解中可取的精确计数集合**（页面以条带圆点展示，
存在多个可取计数的位置高亮为「同优多值」）。

算法：以「最近 k−1 个脉冲取值」为状态做动态规划，状态数 `(P+1)^(k−1) ≤ 5^6 = 15625`，
反向扫描求最优完成代价、正向扫描统计同优集合并贪心构造字典序最小解；最坏规模
（m=300, k=7, 上限 4）在本机约 0.2 秒。

## 页面功能

- 三个输入域（波形 / 响应核 / 脉冲上限），**非法输入不会生效**：计算沿用最近一次有效值，
  并在对应输入域下逐项定位原因（出错项序号与说明）；
- 联动图表：观测 vs 重建、有符号残差（观测 − 重建）、规范脉冲序列与同优计数集合条带，
  指针在任一图表上移动时三图联动并给出位置明细；
- 求解摘要：m / k / n、最小绝对残差和、同优下最小脉冲总数、存在同优计数的位置、耗时。

## 本地开发

```bash
npm install
npm run dev     # 开发服务器
npm test        # vitest：卷积边界 / 双层最优规则 / 同优计数位置 / 暴力枚举对拍
npm run build   # tsc 类型检查 + vite 静态构建（产物在 dist/）
```

## Docker 发布（静态 Web）

```bash
docker compose up -d web          # 构建并在宿主机 8080 端口发布
WEB_PORT=9090 docker compose up -d web   # 宿主机端口可配置（也可用 .env 文件）
```

- Dockerfile 多阶段构建：`node:20-alpine` 完成 `npm ci` 与静态构建，
  `nginx:1.27-alpine` 托管 `dist/`；
- 健康检查：`GET /health` 返回 200（compose 与镜像 HEALTHCHECK 均使用该端点）。

## 一次性校验服务 verify

`verify` 服务不常驻：依次执行代码测试、构建检查、HTTP 冒烟后自行退出，
**退出码即结论**（0 = 全部通过，非 0 = 存在失败环节）：

```bash
docker compose up --exit-code-from verify verify
echo $?        # 0 表示代码测试、构建检查、HTTP 冒烟全部通过
docker compose down
```

校验内容：

1. **代码测试**（vitest）：零边界卷积的越界按零处理、双层最优规则
   （残差和优先、同优取脉冲少、字典序规范解）、存在同优计数的位置
   （`w=[3,1,3], h=[1,1]` 时两个位置的可取计数集合均为 `{0,1}`）、
   以及小规模随机案例与暴力枚举的完全一致对拍；
2. **构建检查**：`tsc --noEmit` 类型检查 + `vite build`；
3. **HTTP 冒烟**：等待 `http://web/health` 返回 200，再校验首页可访问且包含挂载点。

## 目录结构

```
src/solver/convolve.ts   零边界卷积
src/solver/solve.ts      三层规则精确动态规划 + 同优计数集合
src/solver/validate.ts   输入校验（逐项定位非法原因）
src/components/Charts.tsx 联动 SVG 图表
src/App.tsx              页面装配与交互状态
tests/                   vitest 单元测试（含暴力枚举对拍）
scripts/verify.sh        一次性校验入口（测试 → 构建 → 冒烟）
scripts/smoke.mjs        HTTP 冒烟脚本
Dockerfile               多阶段：deps / build / web / verify
docker-compose.yml       web（端口可配置）+ verify（一次性）
nginx.conf               静态托管 + /health 健康检查
```
